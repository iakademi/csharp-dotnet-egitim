# 01 - Temeller

C# dilinin yapı taşlarını tanıtan ilk modül.

## Konular

- Değişkenler, sabitler ve veri tipleri (`int`, `long`, `double`, `decimal`, `bool`, `char`, `string`, `var`)
- Tip dönüşümleri (`(int)`, `Convert`, `int.TryParse`)
- Operatörler ve null birleştirme (`??`, `?.`)
- Koşullu ifadeler: `if/else`, `switch` ifadesi, ilişkisel kalıplar
- Döngüler: `for`, `while`, `foreach`, `break`, `continue`
- Diziler ve çok boyutlu diziler, `^` (sondan) indeksi
- Metotlar: isteğe bağlı parametre, adlandırılmış argüman, `out`, `ref`, `params`, özyineleme
- Tuple ile birden fazla değer döndürme
- `string` metotları ve `StringBuilder`

## Çalıştırma

```bash
cd 01-temeller
dotnet run
```

## Dosyalar

| Dosya | Açıklama |
|-------|----------|

| `Temeller.csproj` | .NET 8 konsol projesi tanımı |
